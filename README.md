# Shrihari Tone Portfolio

React + Vite + Bootstrap portfolio inspired by the clean blue-and-white layout shown in the reference.

## Run

```bash
npm install
npm run dev
```

## Personalize

1. Put your photo at `public/profile.jpg`.
2. Put your resume at `public/resume.pdf`.
3. Update GitHub and LinkedIn URLs in `Hero.jsx` and `Footer.jsx`.
4. Update email, phone and WhatsApp number in `Contact.jsx`.
5. Replace project descriptions/links in `Projects.jsx`.

## Build

```bash
npm run build
```
